# RapidLaTeXOCR Model Bundle

FormulaSnap bundles the official RapidAI RapidLaTeXOCR v0.0.0 ONNX model files from the v0.0.0 GitHub release so that first-use recognition does not need to download model weights separately.

Source: https://github.com/RapidAI/RapidLaTeXOCR  
Release: https://github.com/RapidAI/RapidLaTeXOCR/releases/tag/v0.0.0  
Project license: MIT; see LICENSE.
